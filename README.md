# BLACKFOREX

## TRADE THE GLOBAL MARKETS

BLACKFOREX V1 is a professional web platform foundation for a multi-asset brokerage brand.

### Included
- Public website
- Markets section
- Login and registration UI
- Demo client portal
- Wallet/KYC/IB foundations
- API health endpoint
- Architecture prepared for future authorized MT4/MT5 integrations

> Important: This version is a demo software platform. It does not execute real-money trades, hold client funds, or operate as a regulated broker.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000
